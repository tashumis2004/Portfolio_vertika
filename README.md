# Vertika Mishra – Portfolio (React + Vite)

## Run on your computer
1. Install Node.js (https://nodejs.org), version 18 or newer.
2. Open this folder in VS Code, then in the terminal run:
   - `npm install`
   - `npm run dev`
3. Open the link the terminal shows (usually http://localhost:5173).

## Put it online (Vercel)
1. Push this folder to a new GitHub repo.
2. On vercel.com choose "Add New Project", import the repo and click Deploy.
   Vercel detects Vite automatically (build: `npm run build`, output: `dist`).

## Where to edit
- `src/data.js`: projects, skills, education, links. Add your college name and real GitHub repo links here.
- `src/components/`: one file per section.
- `src/index.css`: all styling and colours (change the variables at the top).
- `src/assets/vertika.jpg`: your photo. Replace it with a bigger, clearer one if you have it.
